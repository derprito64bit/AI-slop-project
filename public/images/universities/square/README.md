# Square university marks

Small square logos shown beside each program in search results.

**These are separate from the wide wordmarks one folder up.** Those are used by
the logo band on the home page and are unreadable at 40px. Put square or crest
style artwork here instead.

## Filenames

Save as `<id>.svg` (preferred) or `<id>.png`, using the id from the first
column below. No code change is needed — the site picks the file up
automatically, and any school without one shows a coloured monogram tile.

## Format

- **Square-ish** artwork: a crest, shield, or icon. Not a horizontal wordmark.
- Transparent background, trimmed tight to the art.
- SVG preferred; otherwise PNG at **200x200 or larger**.
- Avoid art with a baked-in white box — it shows as a white square in dark mode.
